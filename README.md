# 📝 MERN Blogging Platform

A scalable blogging web application built using the MERN stack (MongoDB, Express, React, Node.js). Users can register, log in, and create, edit, or delete blog posts. Images are uploaded via Firebase, and authentication is handled using JWTs.

## 🔧 Features

- Full user authentication with JWT
- Create / Edit / Delete blog posts
- Firebase integration for image uploads
- MongoDB used for data storage
- Clean and responsive UI

## 🛠 Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Storage:** Firebase
- **Authentication:** JWT
